
===

current repository is a fork of keeweb repo.
keeweb -- is a password manager, but this specific aspect is not important for me.
keeweb is also a browser and desktop lightweight multiplatform application -- and this aspect is very important for me.

My goal is to be able to create similar applications with following requirements
- available both in browser and desktop
- multiplatform: macos, linux, windows
- lightweight
- frontend only (no backend)
- data stored in files (local or cloud storage)

based on this repo and my requirements I would like you to reverse engineer it 
and create a plan for me to be able to create similar applications with my requirements.

in this repo I added a folder '!docs' for my files, that are not from the original repo,
so you can add a dedicated sub-folder for your files.
